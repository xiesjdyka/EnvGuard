# EnvGuard：环境预警，一键紧急关闭

用 Claude 或其他软件时，担心代理掉线、出口 IP 变了，或者电脑设置被改了？EnvGuard 帮你盯着这些变化，并留下记录，方便查原因。

你先把环境准备好，让它记住现在的设置。以后检查发现异常，它会提醒你；点红色的“紧急关闭保护软件”，就会强制结束选好的软件及能确认属于它的相关进程。**默认是手动模式，也可以勾选“检测到异常时自动执行紧急关闭”：出口 IP 不符或连续两轮超时，就直接执行同一套关闭流程。**它不会修改系统代理或拦住软件启动。

## macOS 平台支持说明

**macOS 14+，支持 Apple Silicon（M 系列）与 Intel。** 原生 Swift / AppKit 界面，Universal 2 程序包；使用时不用安装 Python、.NET 或 Homebrew。Windows 版的文件、构建与逻辑保持原样，Mac 源码独立放在 [src/macos](src/macos)。

### Mac 怎么开始用

1. 下载 [EnvGuard_macOS_Release.zip](https://github.com/xiesjdyka/EnvGuard/releases/download/v1.2.8/EnvGuard_macOS_Release.zip)，解压整个文件夹，双击 **EnvGuard.app** 或 **环境预警检测器.command**。本版为本地签名，未做 Apple 公证；遇到系统来源提示，按 [Apple 的说明](https://support.apple.com/102445) 在“隐私与安全性”核对来源后打开，不要关闭系统安全检查。
2. 先准备自己的代理和中继。**当前 Mac 移植版检查前置 `7890` 和中继 `20808` 两个本机端口，外网检测走 `20808` 的 HTTP 代理。** 这不是所有代理都能直接套用的通用端口配置器；端口不同需调整源码。它不会替你启动代理或中继。
3. 点“添加保护应用”，选择要保护的 `.app`。点“立即检测”，核对出口、运营商、时区与关闭范围。公网 IP、运营商初始留空，时区取当前设备设置；不要在环境不对时接受基准。
4. 点“确认并保存核心基准”，重新依次核对两站出口并查询运营商，全部核心条件通过才保存。之后点“开始监测”；每 11 秒一轮，8 秒超时，Amazon/ipify 交替。
5. 默认只提醒，需要时手动紧急关闭。想自动处理出口不符或连续两轮超时，明确确认开启“自动紧急保护”。关闭窗口只是隐藏到菜单栏；从菜单栏选择退出或按 **Cmd+Q** 才停止。

每台 Mac 首次都要核对并保存，Windows 的配置不能直接搬过去。**Mac 紧急关闭只覆盖已选 `.app` 内、同用户且身份再次验证通过的进程，不包括包外服务或虚拟机；应用更新后需重新确认。** DNS/WebRTC 辅助信息与核心检测分开展示，未实测不会显示为已验证。

完整 Mac 使用说明、构建方法和测试范围见 [macOS 说明](src/macos/README.md)；局域网下载命令见 [Mac 文件传到 Windows](src/macos/LAN-DOWNLOAD.md)。

## 第一次只要做这几件事

### 1. 连好代理，再选要保护的软件

先确认网络现在能用、出口是你想要的，时区和区域设置也已经准备好。不要在掉线的时候保存环境。

打开 EnvGuard，选择 Claude 或其他要保护的软件。软件还没运行也没关系，可以从“已安装的软件”里选。

添加后会列出紧急关闭的范围，自己看一眼再确认。想出问题时连 Chrome 一起关，就把 Chrome 也加进去；这可能关闭你的其他 Chrome 窗口。不要把整个磁盘或公共文件夹当成某个软件的专用文件夹。

### 2. 找代理软件的“本机端口”

**不用填账号、密码、订阅链接或节点服务器地址。** 这里要的是：代理软件给这台电脑提供连接的那个端口数字。

打开你正在用的代理软件，在设置里找 **“HTTP 端口”或“Mixed / 混合端口”**，把实际数字填进 EnvGuard。不知道在哪，点输入框旁边的“去哪找？”。

**v2rayN 只是一个例子：** 如果它左下角写着 `[mixed:10808]`，就填 `10808`。用其他代理软件，找到对应的本机端口就行，不要照抄这个数字，也不要填卖家给你的服务器端口。

日志位置已经填好了，保留默认就可以；想换位置，点“换文件夹”。

<details>
<summary>如果代理软件里只有 SOCKS 或 TUN，没有 HTTP / 混合端口</summary>

EnvGuard 的网络检查目前需要 HTTP / 混合端口。看看代理软件是否能开启这一类本机端口；如果不能，当前就不能直接用它做这项检查。不要拿其他数字代替。

基础检查不要求选择代理软件的配置文件。额外读取内部配置目前只适配了 v2rayN；其他客户端跳过这个附加选项即可。具体范围见 [技术说明](TECHNICAL.md)。

</details>

### 3. 检测结果，自己确认，再保存

点“检测并核对”，会显示查到的公网出口 IP、时区和关闭范围。确认没问题后，勾选确认，再点“保存并开始监测”。

**其他格子不用全部填满。** “更多检查”里的项目可以先跳过：

- **指定出口 IP：** 不知道就留空，检测后再核对。这里是网站看到的公网出口，不一定等于代理列表里的节点地址。
- **Chrome 设置：** 只是多盯一项“浏览器设置有没有变”，不是防护开关。选择 Chrome 右上角头像对应的那份资料即可，不用自己找文件路径。它记录已保存的语言和相关策略，不会替你改 Chrome。

正常时间流逝和夏令时切换不会被锁死。换到另一台电脑使用时，复制解压后的程序包，再重新做一次以上配置。

## 平时怎么看提醒？

先开 EnvGuard，等它显示检查项和保存时一致，再打开你要用的软件。最小化后，它会留在右下角继续检查。

- **网络没确认：** 每 11 秒检查一轮，每轮只发一个请求：第一轮 Amazon、第二轮 ipify，之后轮流查，每次最多等 8 秒，为链式握手留出时间。一次超时只记日志并显示“正在复核”，连续两轮超时就弹窗报警；查到出口 IP 不符立即提醒，不受超时防抖限制。任一轮正常恢复后，失败次数清零，检测失败不改走直连。
- **检查项已恢复：** 最新检查又通过了，刚才的异常记录仍会保留。
- **需要立即停用：** 点红色“紧急关闭保护软件”，不会等你保存工作，也不会再问一次。
- **想自动关闭：** 在“配环境”页或主窗口勾选“检测到异常时自动执行紧急关闭”。主窗口开启时会让你确认一次，保存后下次启动仍按所选模式运行；触发时不再询问。自动关闭会丢失未保存工作，范围和红色按钮相同。
- **自动保护结果：** 出口 IP 不符立即关闭；连续两轮超时才关闭，单轮超时仍只复核。成功会显示“已自动执行紧急保护”；有残留或权限问题会显示“结束未完全确认”，保留原因和结果日志。其他设置提醒、日志错误仍只预警，可手动关闭。
- **点“知道了”：** 只是收起提醒，不会关闭软件。退出 EnvGuard 就停止检查。

“查看进程范围”可以看它认出了哪些进程；日志按钮可以找到记录。每次提醒、恢复和紧急关闭都会留下记录，写入或关闭失败也会显示原因。发日志给别人前，记得遮掉真实 IP、软件路径等私人信息。

有意换了代理、IP 或环境设置后，点“重新配置”，再次核对后保存。检查通过表示所选检查项和保存时一致，不能用它保证账号不会被限制。

只改自动关闭开关不需要重新采集环境；取消勾选就恢复手动模式。同一轮持续异常只自动执行一次，网络恢复后会重新准备应对下一次异常；未完全关闭时可以再点红色按钮。退出 EnvGuard 后不再自动保护。

### Claude 更新后还要重新选吗？

**Windows 应用包版 Claude 正常更新，不用重新选。** EnvGuard 记住的是应用身份和发布者，不再只记一个带版本号的文件夹。认出同一应用的签名新版后，会接续主程序、你原来确认的专属目录和勾选的服务；旧进程及已识别的子进程也继续保留在关闭范围里。每次接续会留下日志。

之前配置里的官方 Claude 旧路径也会自动接续，**不会借此重新接受 IP、代理或时区**。这些仍按你原来保存的环境检查。

如果换了发布者、入口或服务位置无法验证，才会要求你确认。普通独立 EXE 更新仍需重新选；未知版本的 Cowork 虚拟机也不会只凭名字就被结束，关闭结果会说明。
